MrDomRocks Presents - Kilroy Stonekin's Punch Out Farm - GWAU3 version

With thanks to GWAU3 Community I have put together a working and for the most part fully functional Kilroy Stoneskin Punch Out Farm This farm uses the Smartcast system to use the Brawling Skills used in the Fronis Instance. It's not perfect but it works.

Features: 
*Automated interaction with Kilroy Stonekin, it will pick up the quest related to Fronis Mons Instance Dungeon.
* Fight the foes in each area of the dungeon.
* It will pick up Gold drops, Gold Rarity drops and Lockpicks and Dwarven Ales.  * Pathing to chests that block movement etc.
* Hardmode Selection Avilable
* Bot can now run multiple instances as standard.

Requirements: 
GwAu3 installed
* Extract the zip contents into the Script Folder
* Character Tab requires you complete character name, account login details and GW directory Path per account you wish to launch.
